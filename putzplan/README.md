# TidyHab – Putzplan

Grundgerüst der Putzplan-App für Home Assistant OS mit TypeScript-Oberfläche und eigenem Webserver. Die Bedienung erfolgt über Home Assistant Ingress.

Die Startseite zeigt, ob die Verbindung zum Server funktioniert. Räume, Aufgaben und Putzplanung sind noch nicht implementiert.

Installations- und Betriebshinweise stehen unter **Dokumentation** beziehungsweise in [DOCS.md](DOCS.md).
